# 照护员20题本机模拟操作指南

> **当前版本只用于虚构档案、合成语音和 20 题模拟流程。下文的“老人”“院内流程”都是操作预演说明，不得把这个本机模拟版直接用于真实老人、养老院现场或正式研究。**

## 请先记住这一句

人比系统重要。老人有任何不适、明显不安或表示不想继续时，立即点“暂停练习”，先照顾老人，再处理页面。

## 开始前准备（模拟预演）

请确认：

- 负责人或管理员已建好本次虚构档案和 20 题模拟安排，并确认页面显示“合成模拟 · 20题”。
- 电脑由负责人或管理员启动好，两个页面都能打开；声音服务的合成检查和设备基础检查已经通过。照护员不需要也不应该自己修改这些设置。
- 负责人已把本次老人画面的临时配对 PIN 当面交给扮演老人端的演练人员；PIN 只用于当前场次，不是工作人员账号密码。
- 您使用的是自己的照护员账号，不与别人共用账号。
- 扮演老人端的演练人员已经准备好；本指南不用于真人训练。
- 已知道本班次应该联系哪位负责人，以及院内现行的呼叫方式。

如果任何一项不确定，先不要开始，联系负责人。

负责人需要从一套全新的模拟环境开始时，可在项目目录运行
`./scripts/run-caregiver-demo20.sh`。这个入口会自动准备临时账号、虚构档案、
已审核 20 题安排、合成语音检查和配对 PIN；必须等终端明确显示“照护员本机
演练已就绪”后，才能把屏幕上显示的两个地址、照护员临时账号和 PIN 当面交给
演练人员。按 Ctrl+C 后临时环境会被停止并清理，旧口令和 PIN 不再使用。

## 两个窗口要分开

本机使用时，浏览器需要同时保持两个窗口：

1. **工作人员窗口**：启动完成后显示的、以 `/console` 结尾的本机地址
2. **老人画面窗口**：同一次启动显示的、以 `/patient` 结尾的本机地址

普通本机入口会自动打开两个窗口；一键照护员演练会把两个地址清楚显示出来，
由负责人打开。请把老人画面交给扮演老人端的演练人员，把工作人员窗口留给
照护员操作。两个地址的端口必须完全相同，不能混用上一次启动留下的窗口。

不要只开一个窗口，也不要让老人操作工作人员页面。

## 正常开始一次练习

### 1. 登录

在工作人员窗口使用自己的账号登录。

登录后应看到“照护员操作台”和您的人员编号。如果看到人员不是自己，立即退出，不要继续。

### 2. 核对今天任务

页面会显示今天已安排的练习。核对：

- 服务对象标识；
- 日期和时间；
- 本次练习阶段。

信息不对时，不要点“开始本次”，联系负责人核对。

### 3. 开始本次

信息无误后，点“开始本次”。

点击后不要反复点。页面会自动确认结果。即使当时网络有短暂波动，反复点击也不会更快。

### 4. 确认老人画面

“开始本次”确认成功、工作人员页面已经进入本次场次后，再去老人画面输入
这次启动显示的临时配对 PIN。未开始本次前不能提前配对。

1. 只在地址确认为本机 `/patient` 的老人画面中输入。
2. 点“完成配对”后，等到页面显示当前练习画面，再回到工作人员窗口。
3. 确认工作人员页面显示“老人画面已打开”，再继续下一步。

页面报“当前没有可配对的训练场次”时，先回工作人员页面确认“开始本次”已经
成功，再等几秒重试一次；报“PIN 不正确”、“已过期”或“场次不一致”时，
不要猜测或反复尝试，请负责人核对当前场次后重新发放。

如果一直显示“老人画面还没打开”，不要绕过提示开始。先检查另一个窗口，仍无法连接时联系负责人。

### 5. 开始练习

“开始练习”按钮可点后，点一次即可。

开始后，请始终留在老人旁边，注意老人的表情、情绪和身体状况。不要因为页面在自动进行就离开。

## 练习进行中的五个按钮

### 暂停练习

这是最优先的安全按钮，点一次就会立即开始停止练习。

以下任何情况都应立即暂停：

- 老人明显不安、焦虑、疼痛、头晕或疲惫；
- 老人表示不想继续；
- 声音或画面不对；
- 您觉得现场情况不对劲；
- 您需要离开老人身边。

照护员页面在暂停后不提供重新启动。这是预期的安全设计，不是故障。

### 请求协助

点击后，根据现场情况从列表中选一项。没有自由输入框，不需要写长说明。

提交后：

- 练习会暂停；
- 本机会留下一条记录；
- 页面会提醒您按院内现行方式联系负责人。

**重要：“本机已记录”不等于对方已收到消息。** 您仍需要使用院内电话、呼叫器或当面联系等现行方式请人到场。

### 接管练习

先暂停，等待“接管练习”可点后再点击。

接管后，系统不会再自动向下进行。请您在旁边人工照看和处理，然后选择“结束本次”或联系负责人。

### 结束本次

结束时必须从页面的四个原因中选一个：

- 本次练习已按计划做完；
- 老人表示不想继续；
- 为了老人安全停止；
- 设备或系统无法继续。

只有练习真的全部做完时，才选第一项。如果系统提示还不能按计划结束，不要反复点击，根据实际情况选择其他原因或联系负责人。

### 退出

没有正在进行的练习时，可直接退出。

如果本次还在进行，页面会先尝试安全暂停，只有确认暂停后才会退出。页面如果显示“已阻止退出”，就不要直接关掉窗口，请联系负责人。

## 出现紧急情况时

1. 立即照顾老人，不要等页面反应。
2. 如果伸手可及，点“暂停练习”。
3. 按院内现行紧急处置流程呼叫支援。
4. 情况稳定后，再回到页面请求协助或结束本次。

系统页面不代替院内紧急呼叫、医疗判断或现场人员处置。

## 常见情况

| 页面显示 | 该怎么做 |
| --- | --- |
| “语音服务未准备” | 不要反复点开始，请管理员完成声音服务合成检查。照护员不需要修改设置。 |
| 老人画面要求配对 PIN | 只使用负责人为当前场次发放的临时 PIN；失败时不要猜测，联系负责人重新核对。 |
| “老人画面还没打开” | 检查另一个浏览器窗口是否打开了 `/patient`，不要绕过提示开始。 |
| “正在重新确认状态” | 保持页面打开，不要反复点击。老人不适时先照顾老人并联系负责人。 |
| “这一步还没有确认” | 不要开始另一个任务，等页面自动核对。长时间不变时联系负责人。 |
| “练习已暂停” | 这是安全状态。照护员页面不能重新启动，请接管、请求协助或结束本次。 |
| 按钮是灰色 | 表示现在还不安全或条件未满足，不要刷新页面试图绕过。 |

## 绝对不要做

- 不要共用照护员账号。
- 不要在人员或安排信息不对时开始。
- 不要让老人自己操作工作人员页面。
- 不要在练习进行中离开老人。
- 不要把“本机已记录”当成“负责人已经收到求助”。
- 不要用刷新、关窗口或反复点击的方式绕过暂停和安全提示。
- 不要为了让页面显示“做完”而选择不真实的结束原因。

## 本机版当前边界

当前照护员页面只负责：查看今天任务、开始已安排的练习、暂停、请求协助、接管和结束本次。

它不负责楼层或班次派单，也不会自动把求助发给某位负责人。现场人员分工、求助通道和紧急处置，仍按院内现行流程执行。

**再次确认：这份指南当前只配套“合成模拟 · 20 题”。即使页面和自动检查全部通过，也不表示已完成真实设备、真实老人或养老院现场验收。**
