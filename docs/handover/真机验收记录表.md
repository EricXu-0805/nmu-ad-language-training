## 八项

### 1. 正常题目：声音真正结束后才开麦，而且只开一次

- 观察：AI 读完问句后麦克风才打开；页面上"正在收音"的提示只出现一次。
- 通过判据：肉眼看到朗读结束 → 才出现收音状态；不出现"开了又关又开"。
- 结果：□ 通过 □ 未通过 备注：

### 2. 没有文字回答：一级提示 → 二级提示 → 告知答案，之后不再开第四次麦

- 做法：麦克风开着但不说话，连续三轮。
- 通过判据：三次之后系统告知答案并停止，**不再有第四次收音**。
- 结果：□ 通过 □ 未通过 备注：

### 3. "再说一遍"：同一轮第一次重播、第二次暂停

- 做法：在同一提示层级里说"没听清"两次。
- 通过判据：第一次重播刚才的问题或提示；第二次直接暂停。进入下一提示层级后重新按新一轮计算。
- 结果：□ 通过 □ 未通过 备注：

### 4. 提示后答对：反馈播完并经服务器确认，才进入下一题

- 做法：在一级或二级提示后说出目标词。
- 通过判据：先在**当前题的画面上**听到正确反馈，反馈播完之后才换下一题；不出现"看着橘子听到苹果"。
- 结果：□ 通过 □ 未通过 备注：

### 5. 各种失败：全部关麦并停住，绝不自行恢复

逐项做，每项单独记录：

| 场景 | 做法 | 通过判据 | 结果 |
| --- | --- | --- | --- |
| 拒绝麦克风权限 | 浏览器弹权限时点"拒绝" | 立刻停住并给出可读提示，不重试 | |
| 拔掉/禁用麦克风 | 收音中拔掉外接麦 | 立刻关麦并停住 | |
| 播放失败 | 静音设备或占用音频 | 停住并提示，不跳过题目 | |
| 上传失败 | 断网后说话 | 本机立即关麦并停止继续；能上报就由服务器暂停，不能确认就要求联系负责人 | |
| 断网 | 关 Wi-Fi | 同上，且**不会假装服务器已收到** | |

- 共同判据：以上任何一种都**不算老人答错**，也**不消耗提示次数**。

### 6. 重复操作：只有一个声音、一个麦克风

- 通过判据：全局只有一个声音在放、一个麦克风在用；服务器回执没有重复条目。
- 结果：□ 通过 □ 未通过 备注：

### 7. 暂停 / 切后台 / 刷新 / 断网：立即物理关麦，恢复后不自行开麦

- 通过判据：每一种都**立刻**关麦；恢复后**不会凭旧状态自己重新开麦**。
