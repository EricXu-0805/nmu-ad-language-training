# 配置开关清单

2026-11-05 建。列的是 `app/` 与 `scripts/` 下 Python 代码读取的**全部**环境变量。
`tests/test_config_switch_inventory.py` 逐个对账：代码新读一个变量而这里没有对应行，
或这里有一行而代码已经不读，测试都会红。

**不在这份清单里的：** `harness/` 与 `tests/` 自用的变量；shell 脚本自己的变量
（备份的 `NMU_BACKUP_*`、`scripts/serve.sh` 的 `NMU_STARTUP_TIMEOUT_SECONDS`、
`scripts/ci_gate.sh` 的 `NMU_GATE_PYTHON` 等，见各脚本头注释与 `deploy/systemd/README.md`）；
Compose 层的 `APP_IMAGE`、`CADDY_IMAGE`、卷名等（见 `.env.example`）。

**「生产最近记账」怎么读：** 只抄 `docs/RELEASE_STATE.md`（下称 RS）和 `.env.example`
里带日期的记录，写「未记账」的就是没有任何记录，不等于没设。这一列不是生产实查：
生产应用读 `/opt/nmu/app/.env`（`deploy/systemd/nmu.service` 的 `EnvironmentFile`），
要确认得上机只读核对。密钥只写设没设，值永远不进文档。

**「谁定」：** 有文档写明的照抄并注出处；没有文档写明的一律写「未写明」。「未写明」的项
目前实际是 Eric 按技术默认在设，这是现状，不是谁授权的分工。会改变研究证据的几项另列在
文末「待定」，等钱凯 / PI 定。

应用读的项都来自进程环境，改 `.env` 之后要重启应用才生效；`scripts/` 读的项每次运行现读。
