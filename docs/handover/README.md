## 三句话背景

1. 这是一套给轻中度认知障碍老人做语言沟通训练的研究平台：AI 读题、老人回答、
   系统自动识别与推进，研究者只在卡住时接管；训练数据用于后续研究分析。
2. **它现在不能给真实老人正式使用。** 不是因为程序没写完，而是因为内容冻结、伦理批件、
   隐私评估、真机验收和养老院接收这五类外部条件都还没有。
3. 系统里所有"拒绝"都是设计好的保护。看到某个按钮点不动、某个操作被拒，
   **不要想办法绕过去**，先看提示、再找负责人。
