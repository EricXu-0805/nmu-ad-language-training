# 第 1 周训练前互动（可选）

进入第 1 周关系建立场次后，原流程上方有独立的「训练前互动」卡片。不需要使用时，直接操作下方原流程即可；系统不会自动启动互动。

1. 工作人员根据老人情况，点击「天气／饮食／睡眠／活动」之一，老人端显示并朗读一条开场问题。
2. 工作人员听取老人回答，可以点击「说一句简短回应」，也可以直接「结束互动」。回应为固定中性话术，不根据老人回答生成评判。
3. 需要重新听时点「再播放当前这句」；回应阶段重播的是回应句，不会重新提问。
4. 结束后可以另选话题，或点击「继续关系建立」，回到原来的正式位置。

互动不录音、不转写、不判分、不计入正式题目和完成证据。互动期间原流程的录音、翻题和收尾入口暂时锁住。四主题存放在独立版本内容包中，原第 1 周冻结脚本未改。

暂停、断线或老人端刷新后不会自动重播旧命令；需要工作人员确认后手动重播或重新选择话题。场次恢复后互动可能已处于结束状态，仍需明确继续正式流程。网络结果不确定时只重试原操作，不将旧操作套到新话题上。

## 验收边界

代码回归与合成浏览器可验证按钮、双端状态、乱序保护和不产生录音／评分记录。真平板的播放解锁、锁屏、弱网、外放回声与现场可用性，需要钱凯团队继续实测；技术发布不替代真实设备或临床验收。
