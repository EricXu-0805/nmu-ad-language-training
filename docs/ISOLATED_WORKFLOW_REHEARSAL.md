# 指定起点到复核导出的隔离演练

2026-09-25 新增 [独立 HTTP 演练](../harness/isolated_workflow_rehearsal.py)，补齐此前浏览器走查停在暂停状态、没有验证场次完成与导出的缺口。它使用生产 API 和后台处理代码、全新迁移的临时库及合成音频；不是公网生产账号、云识别或真实平板验收。

演练保持完整 demo20 合同，选择从第 19 题开始。前 18 题留下明确跳过记录，实际回答第 19、20 题，不能称为 20 题全部作答。

1. 仅初始化三个临时具名账号；登录后通过 API 建立模拟档案，明确模拟二次利用许可，执行离线服务检查、创建安排、审核并开始。
2. 配对模拟设备，指定第 19 题；暂停、确认旧命令停止、恢复后仍在同一题，旧命令不重用。
3. 第 19 题模拟识别为空，研究者另行裁定已答对。重放裁定不重复记录，原始识别、AI“沉默”和 0 分保持不变。
4. 第 20 题完成合成回答，服务端结束干预。逐题确认回答、具名锁分、保存收尾、最终完成，全程不直接写数据库补齐业务终态。
5. 数据管理员导出 CSV，核对第 19、20 题总题号、两条录音与锁定复核结果、前 18 条跳过及第 19 题裁定。同一导出意图重复提交仍为同一批次。

本机与同 VPS 隔离运行均完成 61 次 HTTP 请求、2 条作答、2 条锁分、19 条裁定及幂等导出。VPS 使用的 367 个运行期源码／内容文件与当前已安装应用逐字节一致，复制源清单 420 项全部一致。运行时现网应用、备份和发布资料目录不可访问，外网不可用，资源限制为 384 MiB 内存和半核 CPU；运行前后现网服务正常。

HTTP 由 TestClient 驱动，不经过公网代理或真实浏览器。播放／录音结束回执、识别结果和设备行为均为明确仿真；识别后台仍执行原生产工作函数。内嵌 2,578 bytes Opus 仅含合成音调，独立解码为 0.600 秒，容器的 0.608 秒含编码填充；无需在 VPS 安装 ffmpeg。它不能证明老人声音识别准确率、回声抑制、锁屏、弱网或持续并发性能。

## 复跑

在源码目录用现有运行期 Python 启动，提供源码目录外、预先创建且为空的 `0700` 私有目录：

```sh
python -m harness.isolated_workflow_rehearsal --root /absolute/private-empty-rehearsal
```

只使用新建私有根；不加载生产 `.env`，不复制生产库、账号或真实录音。已有应用模块导入、`python -O`、非私有目录、软链接、非空目录一律拒绝。脚本不需要 Git、pytest 或外部网络。退出 `0` 且 `result.json` 的 `status=passed` 才代表该次完整链通过；失败保留现场，不能重用原目录当成新一轮。

目录中 `result.json` 是汇总，`http-events.json` 是请求路径和状态码；另有仅含合成资料的库、录音和导出。运行者核验并受控归档后清理本轮目录，不把它接到公网或改作临床数据库。接口日志不保存登录请求体、会话令牌或 PIN。

[八项回归测试](../tests/test_isolated_workflow_rehearsal.py) 覆盖完整链及幂等、音频字节绑定、四种不安全路径、提前导入应用和关闭断言的拒绝。另有独立无 Git／无默认数据目录副本复跑：禁止外部连接后仍通过，源码哈希未变，默认数据目录未创建。

模拟导出通过不等于正式研究冻结获批。既有 [冻结数据机械演练](../harness/quality_release_scale.py) 与 [护理员现场交接](CAREGIVER_REHEARSAL_HANDOFF.md)、[真实音频容量预算](CAPACITY_REHEARSAL.md) 分别保留独立结论。原始回执在项目父目录 `审核报告_20260925/full-rehearsal/` 受控留存。
