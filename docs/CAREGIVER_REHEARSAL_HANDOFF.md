# 护理员演练与现场交接表

核对日期：2026-09-25。本文依据当前代码与交接资料整理操作范围和待确认项；它不是院方决定、临床批准或一次已经完成的现场验收。实际安装版本与部署证据统一见 [部署状态索引](RELEASE_STATE.md)。

当前护理员简化工作台只接受精确绑定的 `week2-single20-demo-v1` 模拟安排。正式研究账号、内容、设备与院方接收仍按各自门禁处理；不能把研究者账号共享给护理员，也不能通过改数据分类或移除模拟限制来完成演练。

## 当前能做什么

| 身份 | 当前允许的工作 | 当前限制与交接方式 |
| --- | --- | --- |
| 护理员 `caregiver_operator` | 查看本人今日可执行的 20 题模拟安排，开始模拟练习；对本人场次暂停、请求协助、安全接管、按固定原因结束 | 不能创建或审核安排、恢复练习、修改临床事实、锁定研究评分或导出；暂停后找有权处理者，不自行重开 |
| 研究者 `researcher` | 建档、排程；在符合准入条件时操作本人负责的场次、人工裁定、复核录音、确认回答、锁分与完成复核 | 场次按负责人隔离；没有跨受试者研究取数和导出权限；账号技术权限不代替院方任命与研究批准 |
| 数据管理员 `data_steward` | 按权限读取终态记录、审计与完整性检查、去标识导出、研究数据字典与数据接口 | 不能带练、修改临床事实或代替研究者锁分；真实研究总览须绑定冻结发布版本 |
| 管理员 `admin` | 账号管理、监督处理、服务检查及数据治理；符合当前场次门禁时执行训练操作 | 跨场操作保留审计；不能用管理员身份替代知情同意、内容批准、临床判断或现场验收 |
| 老人端配对设备 | 在当前有效场次内播放、录音及上传；随时暂停练习 | PIN 只用于配对，不是工作人员账号；设备没有恢复、锁分、批量取数与导出权限 |

“接管”表示停止自动推进并转为人工照看，不等于获得恢复权限。研究者现场“已答对／跳过”与最终研究锁分也不同：人工纠正必须保留原始记录，最终锁分仍要求绑定录音、具名复核和完整收口。

求助状态按实际发生的事情登记，不以点击次数推断：

| 页面状态 | 它证明什么 | 现场下一步 |
| --- | --- | --- |
| 已登记 | 系统保存了本次求助 | 按院内已确认的电话、呼叫器或当面方式找人；不代表有人收到 |
| 已送达 | 已配置通知通道，并有可验证送达证据 | 等待现场已确定的响应流程；当前未配置通道时此状态不可达 |
| 已接收 | 有权处理者已实际接收 | 核对当前停止状态、原因与责任人 |
| 已处理 | 处理结果已登记 | 是否恢复仍由有权限且已获指定的人另行判断、操作 |

负责人当面到场可以按事实直接登记接收或处理，无需补造“已送达”。当前系统不能承诺自动通知或响应时限。

## 一次安全演练怎样留证

优先使用与现网相同源码和网页产物、同 VPS 上仅监听回环地址的独立服务，通过受控隧道访问。独立服务使用新建的私有临时库、录音、语音缓存与导出目录，不挂生产数据，不复制生产账号、不继承生产密钥、不改公网入口。所有档案和音频均为虚构或合成。运行前核对主机资源，运行后停止服务并按当次保留方案处理隔离目录。

现有 `harness` 要求临时根目录预先存在、权限为 `0700`、位于源码与生产数据目录之外，拒绝外逸路径和符号链接；服务和浏览器验收只接受 `127.0.0.1`。浏览器另核对本次服务实例标识。不要为了访问方便去掉这些检查。

| 验收环节 | 当前可复用入口 | 必须保留的证据与断点 |
| --- | --- | --- |
| 登录、今日安排、开始、配对、一次播报与回答、暂停、求助 | `scripts/run-caregiver-demo20.sh --browser-check start-pause` | 真 Chrome 观察与同一临时数据库核验；本脚本不证明 20 题全部完成 |
| 设备故障恢复、旧录音清理重试 | 上述入口的 `recovery-chains` 模式 | 恢复仍按服务器当前状态；失败不扣临床分、不消耗提示次数 |
| 题内继续、人工“已答对／跳过”、指定题目开始 | `adjudication-chains`、`start-position` 模式 | 保留原题、原录音、题号与裁定理由；跳过不得凭空生成回答或录音 |
| 手动抢答、自动检测声音停播 | `answer-now`、`voice-barge-in` 模式 | 自动停播检测不保存回答开头；停播后提示重新完整回答；合成声不能证明老人现场声学效果 |
| 指定起点到完整收尾和场次导出 | 新增 [隔离 HTTP 全链](ISOLATED_WORKFLOW_REHEARSAL.md) | 本机和同 VPS 隔离库验证从第 19 题开始、前 18 题明确跳过、第 19/20 题作答、裁定、锁分、收尾、完成与幂等导出。临时去标识密钥及模拟二次利用许可只在隔离环境使用；业务终态不灌库。该链使用 TestClient，不能称为 20 题全部实际回答或真实浏览器验收 |
| 冻结研究数据的机械链 | `python -m harness.quality_release_scale --profile smoke --receipt <私有目录中的回执文件>`；完整规模使用 `--profile full` | 此入口直接建立合成证据后测试 cohort、快照、发布和分页，不证明前面的真实带练；完整规模重复第 2 周合同，不代表八周临床内容或实际录音体积通过 |

场次导出必须核验不可变结果汇总、已锁定现场收尾、研究评分与录音证据；保存导出批次清单和校验值，重复提交同一幂等意图不得生成重复批次。去标识表与受控录音副本分开管理，音频含声纹，不能称为匿名数据。

模拟分区取数使用 `data_classification=simulation`，没有冻结纪元，响应 `release=null`。真实研究分区使用已经批准、持久化的冻结版本；提议和批准需要不同的具名角色按治理流程执行。不要为测试而在现网切纪元、填批准人或降低披露阈值。量表工作核对表也不等于正式研究结局或冻结数据。

现网可以另外核验首页、证书、登录入口、认证配置布尔值和匿名拒绝边界；已有受权会话可核验自身身份、服务就绪、数据接口元信息及字典。成功登录会写入会话与审计，认证后的 GET 也可能按五分钟节流更新会话活动时间，因此只称“业务内容只读”，不称“数据库零写入”。不猜密码、不重置真实人员密码；不读取患者明细、录音或转写来做一般页面点击测试。隔离服务通过说明相同主机上的应用链通过，仍不能宣称公网代理、生产账号、云模型和真实研究数据全链通过。

## 目标平板和现场网络怎么测

正式记录使用 [真机验收记录表](handover/真机验收记录表.md) 或 `/acceptance` 向导；每种目标设备、浏览器、麦克风、扬声器和房间都单独留证。先完成 `/device-check`，再用受控模拟档案和合成材料演练。下表补充本轮问题，不能替代原八项。

| 操作 | 观察与通过判据 | 本次结果／证据位置 |
| --- | --- | --- |
| 播报时提前回答；另测只播放外放声音 | 记录是否误停或漏停、检测后能否理解并完整重说；未触发时“现在回答”仍可用。外放回声消失后只恢复同一播报，不重复开麦 | 待现场填写 |
| 轻声、短回答及相邻房间人声 | 分别记录实际触发结果，不预设“能识别人而非电视”；按题号核对是否漏了回答开头 | 待现场填写 |
| 在播报和收音时分别锁屏、切后台、强退 | 播放和麦克风实际停止；回到前台核对当前场次，不能沿旧状态自行开麦；记录中断音频归属 | 待现场填写 |
| 录音前、上传中、保存收尾中分别断网，再恢复 | 页面不假称保存成功；重试保留同一题位和原意图，不重复上传或计分；保存冲突保留草稿并提示核对 | 待现场填写 |
| 重复点击、同时开两个老人页、快速暂停后恢复 | 只有当前有效设备能推进；无重叠声音、双麦克风、跨题录音和重复账本 | 待现场填写 |
| 人工纠正识别错误、超时后才答对、跳题后续训 | 操作者能分清原 AI 结果、现场裁定与锁定研究分；指定起点与导出总题号逐一对应；临床计时和评分口径保持原方案 | 待现场填写 |

验收回执至少包括实际应用构建编号、设备与浏览器版本、网络情形、测试时间、操作人、预期与观察结果、失败截图或日志位置。截图和回执不要包含密码、PIN、令牌或真实受试者资料；模拟通过不代替真实老人理解度与临床效果评估。

| 待确认事项 | 需要填写的决定 | 当前状态 |
