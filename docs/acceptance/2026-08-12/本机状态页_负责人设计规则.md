# 本机状态页——负责人设计规则

这份文件只给负责人和设计人员看。普通用户默认只看到《本机当前状态》。

## 状态由系统决定，用户不选择

按以下顺序命中第一项，页面只能显示一个状态：

1. **已确认停止**：仅用于本轮曾经启动过程序，或出现过异常，且有直接运行证据证明已停止。“本轮从未启动”不归入这一项；用户动作是“不要重试”。
2. **需要负责人处理**：出现错误，或无法确认系统是否已停止；用户动作是“联系负责人”。
3. **正在检查**：实际检查正在进行且尚未结束；用户动作是“不操作”。
4. **可以开始**：实际程序、运行环境和使用流程全部验证完成，并由负责人明确批准；用户动作是“仅在批准范围内开始”。
5. **未准备好**：以上条件都不成立；用户动作是“等待”。

当前应显示“未准备好”。逻辑设计审查通过不能单独触发“可以开始”。

## 自动对话用人话解释

实际界面不展示状态码，只告诉用户正在发生什么：

1. **正在给您读题**：先完整播完，不提前开麦克风。
2. **正在听您说**：用户可以回答；说完可点一次“我说完了”，不点也会自动结束。
3. **正在听懂您的回答**：只需等待，这不是错误，不要重复点击。
4. **我再提示一次**：识别服务正常、但返回空转写时，按当前层级处理：前两次分别给提示并重新听，第三次告知答案且不再开麦；这不代表系统检测到了声学静音。
5. **再说一遍刚才的话**：用户只说“没听清”或“再说一遍”时，同一轮第一次请求会重播刚才的问题或提示；同一轮第二次这样请求会暂停并联系负责人，不消耗正常答题次数。进入下一提示层级后才是新一轮。
6. **给出反馈并继续**：识别出的文字命中预先确定的目标词或允许表达后，先播放对应反馈；反馈播放结束并由服务器确认后，才进入冻结计划的唯一下一位置。连续三次未命中时告知答案，不开启第四次录音。
7. **已停止继续，请联系负责人**：设备或识别服务失败时，能上报就由服务器暂停；断网或无法确认时，本机立即关麦并停止继续，页面显示需要负责人处理，绝不自行恢复。不消耗提示层级，也不让普通用户判断技术原因。

现阶段没有实时“声学静音检测”。系统是在录音结束后，根据有效识别结果决定是重播、给提示还是进入下一步；识别服务异常则暂停。界面不得把“没有转写文字”写成“已检测到您沉默”。

## 首页规则

- 首页只显示：当前状态、现在要做什么、异常时怎么办。
- 首页始终只有一个主要按钮。
- 不能继续时，按钮不可点击，并用一句话说明原因。
- 提示不显示错误码，只说明：发生了什么、是否继续执行、现在该怎么办。
- 颜色只是辅助，每种状态必须同时写清楚文字。
- 技术失败不自动重试；训练内容允许的两级提示，以及每个作答轮最多一次“刚才问题或提示”的重播，按固定上限自动进行，不让普通用户在技术选项之间做决定。

## 高级详情规则

- 高级详情只读，普通用户默认看不到。
- 打开或返回高级详情不得改变任何状态。
- 高级详情不得包含“开始、继续、重试、修复、授权、导入、连接”等操作。
- PM 编号、哈希、错误码、证据链、容量计算、接口名称和审计表格只放在这里。

## 验收标准

没有技术背景的人只看首页，应在十秒内回答：

1. 现在能不能用；
2. 下一步做什么；
3. 程序是“本轮未启动”、“已确认停止”还是“无法确认”；
4. 出问题后要不要重试。

任何一个答案不清楚，都不能交付首页。
