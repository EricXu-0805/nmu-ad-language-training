# 综合修复候选的迁移与上线前核验

本文件是候选的审查要求，不是上线回执。最近登记的现役版本仍为 `c2fd7fd` / `d0c22a6dae2a`；本轮没有操作现役数据库、录音、配置或服务。

## 结构变化

候选迁移 `e2a6d8f0b419` 接在 `d0c22a6dae2a` 后：

- 录音资产与不可变采集收据增加可空 `recording_wseq`，保存开麦时的呈现代次。历史录音保持空值，不编造历史身份。
- 新增只追加 `rapportplaybackreceipt`，将设备实际播放结果绑定场次、命令代次、运行修订和设备能力。
- 对同一场次、同一原始录音的自动回应建立唯一约束。迁移前先检查历史重复；发现重复即停止，尚未创建索引或修改证据。

在受控副本只读检查重复：

```sql
SELECT session_id, raw_audio_id, COUNT(*) AS evidence_rows
FROM rapportutteranceevent
WHERE origin = 'auto' AND raw_audio_id IS NOT NULL
GROUP BY session_id, raw_audio_id HAVING COUNT(*) > 1;
```

若有结果，保留原始数据库和对应发声/TTS 证据，由具名数据治理负责人决定单独的纠正迁移。不得删除行或改 origin 来强行通过。部署前必须记录本次真实检查结果，本地合成无重复不能代表现役也无重复。

## 同一候选的证据

源码提交、五项 CI、前端受控构建清单、完整发布树、迁移头、备份校验器指纹和快照版本必须对应同一候选。工作区构建成功不是受控镜像构建证明。

新版发布树检查的源码范围由 `scripts/verify_deployed_tree.py` 声明；额外/缺失文件及字节差异都会拒绝。前端还必须对照独立保存的 `browser-dist-sha256.json`，并从候选 Git 内容重算输入指纹；不能让部署机自己产生一份清单就为自己背书。

新恢复演练在一次性私有目录执行真正应用生命周期，临时 PIN 不输出，禁止出网与目录外写入；核验恢复库账号的受保护读及核心行数。复制后的数据库和音频必须再次对照已验证源清单，不能仅证明复制前的源快照有效。该结果不证明生产密钥和服务器配置已可恢复，仍需单独留证。

默认恢复演练仅接受当前迁移头，不会自动升级历史快照。对历史快照的受控副本演练须显式使用：

```sh
python -I -B scripts/restore_drill.py /受控快照目录 \
  --migrate-copy \
  --source-verifier /可信归档/verify_backup_snapshot.py \
  --source-verifier-sha256 <独立批准的历史校验器SHA256>
```

历史校验器应来自已批准旧版提交或归档，其指纹须独立保存；不能从待验快照自取一个校验器便认作可信。程序固定执行已经验过指纹的脚本字节，先验源与副本，再迁移副本并按当前合同复验。运行中的生产服务、原始快照和真实账号密码不参与这个隔离启动。

## 部署与回退边界

这轮改变数据库头，前后端需要作为一个版本切换，旧页面必须刷新。旧页面缺少录音代次不能取得新自动回应的控制权，不能靠放宽解析或伪造回执来兼容。

正式维护窗口应先用旧版校验器取得匹配旧头的停写快照，保存旧提交和旧前端构件；在隔离副本完成候选迁移、全量校验、启动与合成核心流程，再按批准窗口切换。新头上线后应安装匹配的新备份校验器、立即形成新头快照并验证异地副本。

回退须匹配旧代码、旧构件、旧校验器和旧头快照，保留失败候选及其新证据。不得对含新播放/录音代次证据的库执行破坏性 downgrade，也不得只换旧应用指向新库。现役仍为裸机时不套用未完成迁移的 Compose 卷切换命令。

## SQLite 并发部署前提

本轮出网与撤销的互斥覆盖同机、同一规范文件路径的 SQLite 多进程，使用数据库旁的私有文件锁，不在等待云服务时占用主数据库写锁。须确保服务进程对数据库父目录有创建私有锁目录的权限；不支持用不同容器路径别名或网络文件系统共享 SQLite 来获得该保证。PostgreSQL 路径保留事务锁机制，本轮本机没有运行 PostgreSQL 实库并发验收。

设备播放回执仅表示当前有效设备报告播放结束，音频传输记录仅表示服务过字节，均不证明受试者实际听见或理解。
