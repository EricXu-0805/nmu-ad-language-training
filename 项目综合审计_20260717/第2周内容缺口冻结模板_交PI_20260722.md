# 第2周内容缺口冻结模板（交 PI 填写）

## 说明

本模板把第 2 周训练脚本中**尚未获得临床冻结、因而无法进入机器可执行运行计划**的内容缺口，逐位置拆成可填写的表格，交由 PI / 临床内容负责人逐项签认。截至当前，源稿 80 个训练位置中只有 20 个单要素命名达到字段级协议完整（且仍为 `qc_status=draft`），其余 **60 个位置存在交付缺口**：20 个双要素左右命名缺自动交互协议、30 个开放回答缺评分 rubric、10 个多要素位置尚未结构化。因为这 60 个缺口，启动门禁按"默认整计划"核验时**当前可启动整场会话数 = 0**，无法开展真实受试者研究。

**红线（所有填写者必须遵守）：训练环节的正确率、AI 判分、提示等级或自由填写分数，绝不能转换、估计或反推为任何正式量表（未训练词标准化命名测验 / 功能沟通量表）的结果。** 本模板只用于冻结"训练内容协议"，与两份正式结局量表的定义/授权是彼此独立的冻结包，不得互相借用数据。

## 5. 验收标准（一个位置何时算"已冻结/可运行"）

一个位置被判为 `frozen/runnable`，**当且仅当同时满足**：

1. **字段完整**：该类字段定义表中的每个"必填"字段均**非空**；无空 rubric、无空沉默分支、无空完成条件。
2. **来源可核**：绑定 `source_document_sha256` + `source_normalized_text_sha256` + 精确段落定位 + 字段摘要；摘要或位置集合变化则该位置自动回落为不可执行。
3. **批准可核**：带内容核对人、PI 批准人、批准时间、批准材料摘要、`protocol_version` 与 definition digest（见第 7 节）。
4. **可接受表达受控**：`acceptable_expressions` 中每一条都绑定来源与批准事实；不接受模型临场扩写。
5. **派生而非手写**：`ready/executable` 由校验器依据上述事实**派生**，JSON 中手写的 `true` 无效。
6. **答案永不下发老人端**：目标词、可接受答案集、rubric 分档、必需概念**只存服务端**；老人端只接收题图与大字号问句，`【物品名】` 槽位由服务端用预置目标词回填、绝不来自 ASR，也绝不把答案内容送到老人客户端。
7. **未知不等于 0/正确**：未识别、沉默、拒答、技术失败不得被换算为"受试者答错"或量表分。
8. **量表红线**：本模板任何字段的产出都不得转换/估计为正式量表结果；两表冻结走独立冻结包。

> 只要 60 个位置中还有任一个不满足以上条件，"默认整计划"仍为不可启动，真实受试者研究保持 NO-GO。

## 6. 什么不用你填（工程已就绪，PI 只需知道边界）

以下能力平台已实现并经本地真实浏览器/回归验证，**不需要 PI 在本模板中提供**：

- **只发当前题图、不泄题**：老人端只显示当前必要内容与题图（`release_scope=simulation_only` 下经私有字节白名单 + blob URL 下发），不显示后台场次事实。
- **无内部 ID 泄露**：opaque 会话事实留服务端，分析后台不再渲染 raw plan/session ID；内部 ID 泄露回归保留为发布门禁。
- **同意/资格门禁**：建档→资格→录音与云处理授权→VisitPlan 审批→到场后训练台只显示已审核且日期已到的安排——这条同意链已成型（Week 1 分层同意话术亦已在脚本内）。
- **命名状态机**：正确/未提及或不知道/相关不准确/沉默>10s 四分支 → 两级提示 → 告知答案，**永不卡题**；成功反馈按进入路径选 `unknown/close/silence` 变体，不混用。
- **独立判定链**：VAD→ASR→Matcher 三阶段各出不可变收据，服务端据完整一致的链**派生唯一终局回执**才允许反馈/推进；`audioSaved` 只证明录音已存、不能直接跳题；技术失败不消耗提示级、不携带 matcher 结论。
- **服务端账本与并发安全**：终局写入用数据库唯一约束 + CAS 冲突收据 + 幂等；删除整条判定链会被恢复校验发现。
- **角色隔离与隐私**：AI 质量后台只对具名 `researcher/data_steward/admin` 开放，只回 overall、不回受试者/场次/题目标识/录音/转写；响应 `private, no-store`。
- **`silence_seconds=10` 窗口**：已在协议内实现（真机建议加 VAD 或研究者把关，此项 PI 可复核但工程已有默认）。

PI/临床只需专注第 1–4 节的**临床内容与协议决策**；上述工程边界不必也不应由本模板重写。
