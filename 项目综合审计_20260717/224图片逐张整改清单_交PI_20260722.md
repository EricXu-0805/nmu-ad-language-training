## 一、总览：为什么图片仍被硬阻断

- **规模**：当前 **18 条开放发现**，其中 **17 条 blocking**（正式图片路由不可开），**1 条 review**（跨周字节重复需确认）。
- **17 条 blocking 的构成**：
  - **3 条答案泄题**——图里直接画出/写出场景答案文字（`wk2-multi-01`=动物园、`wk2-multi-02`=公园、`wk8-multi-02`=动物园）。
  - **14 条映射冲突**——文件名 / Word 标题 / 像素左右方位 / 作用提示方向 / 目标词粒度 之间互相矛盾（`wk2-21`、`wk3-29`、`wk3-30`、`wk4-21`、`wk4-25`、`wk5-25`、`wk5-30`、`wk6-23`、`wk6-28`、`wk7-21`、`wk7-23`、`wk8-26`、`wk8-27`、`wk8-28`）。
- **1 条 review**：`wk3-multi-01` 与 `wk6-multi-01` 为字节完全相同的跨周复用（914×930），需 PI 确认是有意训练设计还是资产误配。
- **`wk2-30` 已有勘误记录，不重复列为开放问题**。

**为什么这是内容 / 版权问题，不是交付工程问题（关键澄清，交 PI 时务必讲清）：**
工程侧已在**交付环节**堵死答案泄露，不需要再为此改代码——
1. **仅当前题位服务（current-only）**：图片字节只在"当前已配对设备 + 当前 live session + 当前题位 / 当前自动命令"共同授权下经专用接口返回；旧公开静态路由 `/img/*` 已下线并返回 404。
2. **不下发 id / 答案**：客户端计划、患者呈现和自动命令都不再含 `image_id`；DOM 只持有短期 `blob:` URL；老人端 URL、文件名、`alt` 文本、客户端 manifest 均不含目标词或答案。
3. **manifest 全部 `public_path=null`、`release_status=blocked_pending_approvals`**，`ready_for_research` 保持 false，导入成功本身永不写这个状态。

因此 17 条 blocking **不是"图片会漏答案给老人"的交付风险，而是内容定义（左右/目标词/rubric）未冻结、素材本身泄题、以及版权来源未闭合**——必须由 **PI + 临床 + 美术 + 版权**在**内容与权利层**裁决，导入脚本不得靠"文件名 / Word 标题 / 看到的左右位置"三选一静默修复。

## 四、验收标准（一张图"可放行"的充要条件）

一张图片只有**同时满足以下全部条件、且由两名独立评审（视觉 + 临床）分别签认**后，其对应题位方可从 `blocked/quarantined` 升为 `reviewed→frozen`：

1. **无可见答案文字**：图面不含目标词、场景名或任何直接泄题文字（3 张泄题图须先去字派生并复核）。
2. **左右方位与目标映射一致**：文件名 / Word 标题 / 像素左右 / 作用提示方向 / 目标词粒度**四方一致**，由 PI 冻结为唯一权威映射，孪生图同步；题库、话术、图片摘要三者对齐。
3. **目标词与可接受表达已冻结**：目标词、acceptable expressions、纠正分支由 PI 明确；模型不得临场扩写同义词或用上位词充当精确答案。
4. **适老分辨率与呈现达标**：在**真实老人端设备**上逐张检查主体大小、双要素左右间距、黑白线条对比、反光/低亮度可辨识度；桌面浏览器截图通过**不算数**。低分辨率资产（83 张至少一边 <300px，最小 112px/94px）须回源端补高清或生成有来源链的展示派生版，**不得直接放大或覆盖原图**。
5. **版权来源闭合**：第三节全部字段齐备，`rights_status` 非 `quarantined`，且授权覆盖数字化施测 / 派生修改 / 分发。
6. **双人独立签认**：`visual_qc_status` 与 `clinical_qc_status` 由两名互不覆盖的评审分别通过；重复复用（review 项）写明理由；泄题图显式判定去字方案。
7. **门禁不因导入放宽**：以上全部留证通过后，服务器才可就该题位派生放行；`ready_for_research=true` 仍须内容协议、临床双人冻结、伦理/版权、autopilot scope、真机与供应商验证**全链闭合**方可置真，**导入成功本身永不写此状态**。

> 状态机：`blocked_pending_approvals`（当前全部）→ 关闭对应 finding + 三类 approval（rights / visual / content）转 `approved` → `reviewed` → definition digest 冻结 `frozen`。任一图片字节、映射或批准事实变化都必须升级版本、重算 digest、重新审核，不得原地替换已绑定场次的资产。
